# Textify
A program to convert image and video files into ASCII art.<br>
Pretty pointless, but just a fun side project to work on when I'm bored.<br>

## Current Features
### C
- Sequence conversion & playback
### Go-new (dropped)
- Auto ffmpeg integration
- Sequence conversion & playback
### Go-old (dropped)
- Image conversion
- Sequence conversion & playback

## Future Update Goals:
- Saveable text
- Synced audio playback
- Linux support
- Terminal color (option)?
